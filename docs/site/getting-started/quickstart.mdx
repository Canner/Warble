## What this page will cover

- `warble compile examples/render-demo -o ir.json` — turning a profile + components + context into IR JSON.
- `warble dispatch ir.json --target claude-code:headless --out agent` — emitting native Claude Code agent files from the IR.
- Running the emitted agent (`claude -p --agent …`) against a `wren`-queryable semantic layer, then producing a dashboard with `warble render`.
