## What this page will cover

- `warble eval ablate` — per-step tier ablation to find which steps can drop to `cheap` without losing accuracy.
- `warble eval gate` — a CI regression gate with a non-zero exit on an accuracy drop, and `warble eval verify-context` for stale-golden detection against the MDL SHA.
- Turning a confirmed run into a new golden with `warble eval capture`.
