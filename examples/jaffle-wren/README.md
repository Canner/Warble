# Jaffle Wren eval fixture

This directory is the authored Wren project used by the accuracy eval. Its raw models, views,
relationships, cubes, instructions, DuckDB fixture, and `wren_project.yml` are checked in.
`target/mdl.json` is generated by `wren context build` and is not committed.

`wren_project.yml` is checked in using the Wren CLI's canonical formatting so rebuilding the MDL is
idempotent and does not dirty the repository. Treat a diff in that file after a build as a canonical
format change that must be reviewed and committed deliberately.

The manifest's `catalog: wren` and `schema: public` identify this MDL project inside Wren Engine.
They are not the DuckDB database's catalog or schema. Database catalog and schema values belong in
each model's `table_reference`.
